# User Guide

Step-by-step guidance for clinicians and wet-lab scientists — no command-line
experience assumed beyond copying three setup commands. Chapters are ordered
the way you will meet them: get oriented, install, set up datasets, then run
your first analysis.

If you want the technical depth behind any step, every chapter links into the
[Reference](reference.md) section.
